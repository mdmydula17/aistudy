## 🏛️ 一、 The Auto Governance Layer (自动化宪法与演进规约)
为了防止上下文漂移和架构腐化，本项目建立三道防线：

1. **AST 宪法审计 (Static Constitution Tests)**
    - 必须在 `tests/architecture/` 下生成基于 `ast` 模块的脚本。
    - **红线约束**：`app/api` 绝对禁止 import `app.crud` 或 `models`；`app/graph` 绝对禁止 import `fastapi`；`app/schemas` 必须是零依赖的纯粹 Pydantic 定义。
2. **分布式上下文压缩 (Context Compression)**
    - 每建立一个核心目录（如 `api`, `graph`, `crawler`），必须在其下生成 `README.ai.md`。
    - 内容须指明该目录的 **ONLY (唯一职责)** 和 **FORBIDDEN (禁止行为)**。
3. **修宪演进协议 (The Evolution Protocol)**
    - 严禁通过散装对话修改底层 Schema。如有结构变更，必须进入 `[Phase 0: 修宪]` 流程：更新 `schemas/`$\rightarrow$ 更新相关契约测试 $\rightarrow$ 记录至根目录 `CHANGELOG.ai.md`。

## 📝 三、 核心机器可验证契约 (Machine-Verifiable Contracts)
系统流转的血液是严格校验的 JSON/Pydantic 模型。所有 LLM 输出必须通过以下契约验证，否则触发重试。

Python

```plain
# app/schemas/asset.py
from pydantic import BaseModel, Field
from typing import List, Dict

class ExtractedAssetData(BaseModel):
    title: str = Field(..., description="剔除情绪化表达后的核心标题")
    core_logic: str = Field(..., description="底层逻辑或高频共识总结 (Markdown格式)")
    actionable_sop: List[Dict[str, str]] = Field(..., description="可落地的结构化步骤，格式为 [{'step': '1', 'action': '...', 'detail': '...'}]")
    confidence_score: float = Field(..., description="AI 评估提取内容的置信度 (0.0 - 1.0)")
```

Python

```plain
# app/graph/state.py
from typing_extensions import TypedDict
from typing import List, Optional

class GraphState(TypedDict):
    task_id: str
    url: str
    raw_text: Optional[str]
    image_urls: Optional[List[str]]
    ocr_text: Optional[str]
    structured_data: Optional[dict]  # 必须符合 ExtractedAssetData 结构
    needs_human_review: bool         # HITL 逃生舱标志位
    error: Optional[str]
```

## ⚙️ 四、 LangGraph 流水线与容错机制 (Assembly Line & HITL)
工作流采用严格的单向状态图设计。必须无缝集成 **LangSmith**（或等效追踪系统）用于观测 Agent 的 Thinking Process。

1. `**node_crawl**`: 调用 `crawler/xiaohongshu.py` (仅限 DrissionPage)，提取正文与图片链接。
2. `**node_vision**`: 若存在图片，调用多模态模型提取文字追加至 `ocr_text`。
3. `**node_extract**`: 聚合文本，调用大模型并强制验证 `ExtractedAssetData`。
    - **HITL (人类介入逃生舱)**: 若连续 3 次解析失败，或 `confidence_score < 0.6`，不抛出崩溃异常，而是将 state 中的 `needs_human_review` 设为 `True` 并挂起，交由前端 Dashboard 人工接管。
4. `**node_save**`: 调用 `crud` 落库，完结图流转。

## 🚦 五、 相变驱动执行协议 (Phase-Driven Execution)
AI 必须等待人类输入以下指令后方可执行对应阶段任务：

+ `**[Phase 1: 建立宪法与契约基座]**`
    - 任务：生成 `models`, `schemas`, `crud` 以及 `tests/architecture` 和 `tests/contracts`。
    - 放行标准：所有 AST 审计测试与 Pydantic 验证测试必须 100% 绿灯。
+ `**[Phase 2: 收割机引擎接入]**`
    - 任务：生成 `crawler` 层。
    - 放行标准：在无 LLM 介入下，DrissionPage 能够稳定输入小红书 URL 并吐出干净的 `raw_text` 与 `image_urls` 字典。
+ `**[Phase 3: 组装自治流水线]**`
    - 任务：生成 `graph` 层，将爬虫与 CRUD 封装为 Node，并配置 LangSmith Trace 和 HITL 逻辑。
    - 放行标准：通过 Mock LLM 数据跑通完整的 Graph 流转图测试。
+ `**[Phase 4: 暴露 API 与前端管控台]**`
    - 任务：生成 `api` 层路由，并在独立目录下初始化 Vue 3 + Vite 中后台项目，实现任务分发与资产人工核验界面。
